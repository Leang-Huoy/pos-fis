## របៀបដំណើរការ (How to Run)

### ជម្រើសទី ១: ចុចបើក File `run.bat`
ចុចទ្វេដង (Double-click) លើឯកសារ `run.bat` ដើម្បីដំណើរការកម្មវិធីភ្លាមៗ។

### ជម្រើសទី ២: បើកតាមរយៈ Browser ផ្ទាល់
ប្រសិនបើ Server កំពុងដំណើរការ សូមបើក Browser ទៅកាន់ [http://localhost:8501](http://localhost:8501)

### ជម្រើសទី ៣: ដំណើរការតាមរយៈ Terminal / CMD
```bash
python -m streamlit run app.py
```

   - **🔗 ភ្ជាប់ស្វ័យប្រវត្តជាមួយវិក្កយបត្រ និងសំណើទូទាត់**: នៅពេលអ្នកប្រើជ្រើសរើសឈ្មោះសាលារៀន ប្រព័ន្ធនឹងទាញយកឈ្មោះអ្នកផ្គត់ផ្គង់ មុខទំនិញដែលគាត់ផ្គត់ផ្គង់ អាសយដ្ឋាន លេខទូរស័ព្ទ និងហត្ថលេខារបស់គាត់មកបំពេញ និងជ្រើសរើសឱ្យដោយស្វ័យប្រវត្តិ។
3. **📦 កំណត់តម្លៃតាមសាលា ឬតាមឃុំ និងបញ្ជីមុខទំនិញស្ដង់ដារទាំង ៦១ មុខ (School/Commune Pricing & 61 Standard Items)**:
   - **🎯 ជម្រើសកម្រិតកំណត់តម្លៃ (Price Level Selection)**:
     - **🏫 តាមសាលារៀន (School Level)**: កំណត់តម្លៃជាក់លាក់ដោយឡែកសម្រាប់សាលានីមួយៗ ដោយជ្រើសរើស ខេត្ត -> ស្រុក -> ឃុំ -> សាលារៀន។
     - **🏛️ តាមឃុំ/សង្កាត់ (Commune Level)**: កំណត់តម្លៃរួមសម្រាប់ឃុំមួយ ដែលគ្រប់សាលាក្នុងឃុំនោះនឹងប្រើប្រាស់តម្លៃនេះជាគោល។
     - **🔄 ប្រព័ន្ធទាញយកតម្លៃវៃឆ្លាត (Smart Fallback)**: ប្រសិនបើសាលាមានតម្លៃដោយឡែក ប្រព័ន្ធនឹងប្រើតម្លៃសាលា; ប្រសិនបើគ្មាន ប្រព័ន្ធនឹងទាញយកតម្លៃរួមតាមឃុំដោយស្វ័យប្រវត្តិ។
   - **📋 បញ្ជីមុខទំនិញស្ដង់ដារទាំង ៦១ មុខ (តាមគំរូរូបភាព)**:
     - ដាក់បញ្ចូលបញ្ជីមុខទំនិញស្ដង់ដារទាំង ៦១ មុខក្នុងទម្រង់ Dropdown/Selectbox រៀបតាមលំដាប់លំដោយដូចក្នុងរូបភាពគំរូ ព្រមទាំងមានជម្រើសវាយបញ្ចូលឈ្មោះទំនិញថ្មីបន្ថែម។
   - **🏷️ ចាត់ថ្នាក់ប្រភេទស្វ័យប្រវត្តិ (Auto-classification)**:
     - នៅពេលជ្រើសរើស ឬវាយឈ្មោះទំនិញ ប្រព័ន្ធនឹងចាត់ថ្នាក់ចូលទៅក្នុង ៥ ប្រភេទស្ដង់ដារដោយស្វ័យប្រវត្តិ៖ **អង្ករ**, **ប្រេងឆា**, **អំបិល**, **ត្រី សាច់ ស៊ុត**, និង **បន្លែ** (រួមទាំងករណីពិសេសដូចជា ស្ពៃជើងទា, ស្ពៃបូកគោ, សណ្តែកគួរ ដែលចាត់ជាបន្លែបានយ៉ាងត្រឹមត្រូវ ១០០%)។
   - **⚡ ប៊ូតុងមួយឃ្លីកបញ្ចូលមុខទំនិញទាំង ៦១ មុខ (One-Click 61 Items Batch Seed)**:
     - អាចបញ្ចូលមុខទំនិញស្ដង់ដារទាំង ៦១ មុខ ព្រមទាំងតម្លៃវគ្គ១-២ និងប្រភេទសម្គាល់ ចូលទៅក្នុងសាលា ឬឃុំដែលបានជ្រើសរើសភ្លាមៗដោយចុចតែមួយឃ្លីក។
   - **📅 កំណត់កាលបរិច្ឆេទវគ្គរួម**: អាចកំណត់កាលបរិច្ឆេទវគ្គ១ និងវគ្គ២ ដល់មុខទំនិញទាំងអស់ក្នុងសាលា ឬឃុំតែម្ដង (Batch update)។
   - **⚡ គណនាស្វ័យប្រវត្តិតាមកាលបរិច្ឆេទ**: នៅត្រង់ទម្រង់កត់ត្រាការលក់ប្រចាំថ្ងៃ និងវិក្កយបត្រ ប្រព័ន្ធនឹងផ្ទៀងផ្ទាត់ដោយស្វ័យប្រវត្តថាស្ថិតក្នុងចន្លោះកាលបរិច្ឆេទនៃវគ្គណា (វគ្គ១ ឬ វគ្គ២) រួចចាប់យកតម្លៃឯកតានៃវគ្គនោះមកគណនាតម្លៃសរុបជូនដោយស្វ័យប្រវត្តិ។
   - **🟢/🔵 បង្ហាញស្ថានភាពវគ្គបច្ចុប្បន្ន**: ក្នុងតារាងបញ្ជីមុខទំនិញ មានជួរឈរបង្ហាញស្ថានភាពថាទំនិញកំពុងស្ថិតក្នុងវគ្គណា (ឧទាហរណ៍៖ `🟢 កំពុងអនុវត្ត វគ្គ១` ឬ `🔵 កំពុងអនុវត្ត វគ្គ២`) ដោយស្វ័យប្រវត្តិតាមថ្ងៃបច្ចុប្បន្ន។
4. **📥 នាំចូលទិន្នន័យពីក្រៅពហុទម្រង់ (Universal Importer)**:
   - គាំទ្រការទាញយកទិន្នន័យពីឯកសារ **Excel (`.xlsx`, `.xls`)**, **Word (`.docx`, `.doc`)**, **CSV**, **PDF**, និង **រូបភាព (`.png`, `.jpg`, `.jpeg`) តាមរយៈបច្ចេកវិទ្យា OCR**។
   - មុខងារនេះមាននៅលើគ្រប់ផ្នែកសំខាន់ៗ៖
     - **📦 បញ្ជីមុខទំនិញ**: នាំចូលមុខទំនិញ និងគណនាតម្លៃមធ្យមស្វ័យប្រវត្តិ
     - **📍 ទីតាំងរដ្ឋបាល**: នាំចូលខេត្ត ស្រុក ឃុំ ភូមិ
     - **🏫 សាលារៀន**: នាំចូលឈ្មោះសាលា និងទីតាំង
     - **🚚 អ្នកផ្គត់ផ្គង់**: នាំចូលឈ្មោះអ្នកផ្គត់ផ្គង់ អាសយដ្ឋាន និងលេខទូរស័ព្ទ
     - **📝 កំណត់ត្រាប្រចាំថ្ងៃ**: នាំចូលកំណត់ត្រាលក់ និងគណនាតម្លៃសរុប (បរិមាណ × តម្លៃរាយ) ស្វ័យប្រវត្តិ
   - **✏️ ផ្ទៀងផ្ទាត់ និងកែប្រែទិន្នន័យបាន (Editable Data Editor)**: ក្រោយពេលស្រង់ទិន្នន័យពីឯកសារ ទិន្នន័យនឹងត្រូវបង្ហាញក្នុងតារាងដែលអាចចុចកែប្រែផ្ទាល់ បន្ថែមជួរ ឬលុបជួរបានមុនពេលសម្រេចចិត្ត Save ចូល Database។
   - **📑 ទាញយកគំរូ Excel (Download Sample Template)**: មានប៊ូតុងទាញយកឯកសារគំរូ Excel សម្រាប់ផ្នែកនីមួយៗ។
5. **🔢 លេខរៀងរៀបតាមលំដាប់ (ល.រ ចាប់ពីលេខ ១ ដល់ N)**:
   - គ្រប់តារាងទាំងអស់ក្នុងប្រព័ន្ធ សុទ្ធតែមានជួរឈរ `ល.រ` ចាប់ផ្ដើមពីលេខ **១** រហូតដល់លេខចុងក្រោយយ៉ាងត្រឹមត្រូវ។
6. **🇰🇭 រូបិយប័ណ្ណប្រាក់រៀល (៛) ពេញលេញ**: ប្រព័ន្ធទាំងមូលត្រូវបានប្តូរទៅប្រើប្រាស់ប្រាក់រៀល (៛) ទាំងក្នុងផ្ទាំងគ្រប់គ្រង វិក្កយបត្រ របាយការណ៍ និងការទាញយកជា Excel/PDF។
7. **✏️ មុខងារកែប្រែ និង 🗑️ លុប**:
   - **ទីតាំងរដ្ឋបាល**: អាចជ្រើសរើស ID ទីតាំងដើម្បីកែប្រែ ឬលុប។
   - **គ្រប់គ្រងសាលារៀន**: អាចជ្រើសរើសសាលាដើម្បីកែប្រែ ឬលុប។
   - **បញ្ជីមុខទំនិញ**: អាចកែប្រែ ឬលុបមុខទំនិញ។
   - **អ្នកផ្គត់ផ្គង់**: អាចកែប្រែ ឬលុបអ្នកផ្គត់ផ្គង់។
8. **📊 គណនាតម្លៃមធ្យមដោយស្វ័យប្រវត្ត (Average Price)**:
   - នៅក្នុងបញ្ជីមុខទំនិញ តម្លៃមធ្យម `(តម្លៃវគ្គ១ + តម្លៃវគ្គ២) / ២` ត្រូវបានគណនា និងបង្ហាញបន្ទាប់ពីតម្លៃវគ្គ២ ដោយស្វ័យប្រវត្តិ។
9. **📍 ជ្រើសរើសទីតាំងរដ្ឋបាលបន្តគ្នា (Cascading Selection)**:
   - ជ្រើសរើស ខេត្ត/ក្រុង -> ស្រុក/ខណ្ឌ -> ឃុំ/សង្កាត់ -> ភូមិ និងអាចវាយបញ្ចូលថ្មីប្រសិនបើគ្មានក្នុងប្រព័ន្ធ។
10. **🏫 ស្វ័យប្រវត្តិចាប់យកឈ្មោះសាលារៀន (Auto-detect School by Commune)**:
    - ស្វ័យប្រវត្តិចាប់ទាញយកឈ្មោះសាលារៀនទាំងអស់ក្នុងឃុំនោះមកបង្ហាញ និងអាចវាយបន្ថែមបាន។
11. **📝 កត់ត្រា និងចេញវិក្កយបត្រប្រចាំថ្ងៃ**: កត់ត្រាការទិញ-លក់តាមសាលា និងទាញយកវិក្កយបត្រជា Excel/PDF (ទំហំ A5) គិតជាប្រាក់រៀល (៛)។
12. **📑 សំណើសុំទូទាត់ប្រចាំខែ (Monthly Payment Proposal - ទំហំ A4)**:
    - **យកគំរូតាមឯកសារស្កេន ១០០% (Scanned Proposal Template)**:
      - ក្បាលឯកសារ៖ `ព្រះរាជាណាចក្រកម្ពុជា`, `ជាតិ សាសនា ព្រះមហាក្សត្រ` (ពុម្ពអក្សរមូល Khmer OS Muol Light)។
      - ព័ត៌មានស្ថាប័ន៖ `ក្រុង/ស្រុក/ខណ្ឌ`, `ឃុំ/សង្កាត់`, `សាលាបឋមសិក្សា` និង `លេខសក្ខីប័ត្រ ៖ 0008` (ពណ៍ខៀវដិត)។

13. **🛒 បញ្ជីទិញទំនិញចូល & ជំពាក់អ្នកផ្គត់ផ្គង់**:

    - **🏢 គណនីការិយាល័យអប់រំស្រុក (២១០ គណនី: `0102` ដល់ `2507`)**: មើល និងកែប្រែបានទិន្នន័យពេញ ១ ស្រុករបស់ខ្លួន។ មិនអាចមើលឃើញ ឬកែប្រែទិន្នន័យស្រុកផ្សេងឡើយ។

    - **🚫 លុបគណនីសាលារៀន**: គណនីសាលារៀនត្រូវបានលុបចេញពីប្រព័ន្ធ ទុកត្រឹមថ្នាក់ឃុំ ស្រុក ខេត្ត និង Admin។
16. **📍 គ្រប់គ្រងទីតាំង និងសាលារៀនបឋមសិក្សាទូទាំងប្រទេសកម្ពុជា (National MoEYS Locations & Primary Schools)**:
    - បញ្ចូលទិន្នន័យទីតាំងរដ្ឋបាល និងសាលារៀនបឋមសិក្សាគ្រប់ **២៥ រាជធានី-ខេត្ត** ទូទាំងព្រះរាជាណាចក្រកម្ពុជា (២១០ ក្រុង/ស្រុក/ខណ្ឌ, ១,៦៥២ ឃុំ/សង្កាត់, ១៤,៥៨៤ ភូមិ និង ៤,៥១៧ សាលាបឋមសិក្សា)។
    - **✂️ សម្អាតឈ្មោះសាលារៀន**: គ្រប់សាលាបឋមសិក្សាទាំងអស់ ត្រូវបានលុបពាក្យ «សាលាបឋមសិក្សា» ចេញ ដោយទុកត្រឹមឈ្មោះពិតក្រោយដកឃ្លា (ឧ. «ភ្នំដី», «ស្លែងស្ពាន»...)។
    - **🔍 តម្រងជ្រើសរើសបន្តគ្នា (Cascading Filters)**:
      - ជ្រើសរើស ខេត្ត/រាជធានី (២៥ ខេត្ត) ➔ ស្រុក/ខណ្ឌ/ក្រុង (ដកស្រង់ស្វ័យប្រវត្តិតាមខេត្ត) ➔ ឃុំ/សង្កាត់ (ដកស្រង់ស្វ័យប្រវត្តិតាមស្រុក) ➔ ស្វែងរកតាមឈ្មោះភូមិ សាលា ឬលេខកូដ។
    - **📥 នាំចេញទិន្នន័យជា Excel (.xlsx) និង PDF (.pdf) តាមការជ្រើសរើស**:
      - 📥 **ទាញចេញជា Excel (.xlsx)**: រៀបចំតាមទម្រង់ស្តង់ដារ មានពុម្ពអក្សរខ្មែរ ក្បាលតារាងពណ៌ខៀវ បន្ទាត់ក្រឡាស្អាត និងលេខរៀង ល.រ ស្របតាមតម្រងដែលបានជ្រើសរើស។
      - 📄 **ទាញចេញជា PDF (.pdf)**: បង្កើតជារបាយការណ៍ផ្លូវការតាមបច្ចេកវិទ្យា Headless Browser មានក្បាលលិខិតជាតិ ចំណងជើង និងទិន្នន័យត្រឹមត្រូវ ១០០%។
17. **👥 គ្រប់គ្រងគណនីអ្នកប្រើប្រាស់សម្រាប់ Admin (Admin User Management Tool)**:
    - **🛠️ ប៊ូតុងកែប្រែ និងលុបគណនី (Edit & Delete Buttons)**:
      - **✏️ ប៊ូតុងកែប្រែគណនី**: អាចកែប្រែឈ្មោះពេញ តួនាទី ដែនសមត្ថកិច្ចរដ្ឋបាល (ខេត្ត ➔ ស្រុក ➔ ឃុំ) និងប្តូរពាក្យសម្ងាត់ថ្មី។
      - **🗑️ ប៊ូតុងលុបគណនី**: មានប្រអប់បញ្ជាក់ការលុបច្បាស់លាស់ និងមានសុវត្ថិភាពខ្ពស់ (មិនអនុញ្ញាតឱ្យលុបគណនីដែលកំពុង Login ឬលុប Admin ចុងក្រោយឡើយ)។
    - **➕ បង្កើតគណនីថ្មីតាមថ្នាក់ (Tiered User Creation)**: អាចបង្កើតគណនីថ្មីតាមថ្នាក់ខេត្ត ស្រុក ឃុំ ឬ Admin ដោយជ្រើសរើសទីតាំងរដ្ឋបាលបន្តគ្នា។
    - **📊 ផ្ទាំងបង្ហាញស្ថិតិគណនី ៥ ជួរ**: គណនីសរុប (១,៨៨៨), Admin (១), មន្ទីរខេត្ត (២៥), ការិយាល័យស្រុក (២១០), និងរដ្ឋបាលឃុំ (១,៦៥២)។
